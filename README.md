# User Experience Evaluation Playbook

本项目是可独立运行的静态演示网页，包含27页用户体验评测内容。无需安装前端依赖。

## 本地预览

在仓库根目录运行：

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

打开 http://127.0.0.1:8767/ 。也可直接打开 `index.html`。

## 使用方式

首页独占整屏，第二页起显示同底色的轻量目录。目录收起后完全隐藏，仅保留内容区展开按钮；不显示页码、进度及翻页按钮。全屏和完整提纲入口仍在目录下方。

滚轮/触控板按页翻动，惯性不连续跨页；支持方向键、PageUp/PageDown、Home/End。手机长页先阅读本页内容，到边界后通过下一次手势翻页。宽表格保持局部横向滚动。

按最新提纲组织为27页，6张源表共27行（页面呈现3张表，四个判断方向改为插图分区、两个观察面改为独立区块、六类信号改为插画卡片）、24条规范及来源完整保留。Neuron与Ohm版本分别保存。

## 更新与导出

独立使用仓库时，修改 `提纲原文.md` 后运行：

```sh
python3 build_content.py
```

在原始工作目录中，脚本优先读取上级目录的 `测试阶段用户体验评测分享提纲.md`；独立仓库中自动使用本地 `提纲原文.md`。页面中的定制排版和内容精简由 `build_outline.py`、`slides.js` 与 `content-layout.css` 保留。

`python3 export.py` 在上级目录导出网页 ZIP 包。运行资源均为本地文件。`figures/` 保存 Hairline 插画源文件和可独立打开的 HTML；检查截图等临时产物不纳入版本控制。
