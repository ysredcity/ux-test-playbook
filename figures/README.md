# 四个体验判断方向 · Hairline 插图

台钳对应实用性：指针横移带动活动钳口与螺杆，工件在钳口间；卡架对应可用性：指针选中卡片，卡片抬起、相邻卡片按距离展开；坡道对应公平性：指针调整坡度，高端平台与扶手同步；唱片机对应愉悦性：指针带动唱臂和唱片标记。

每幅为独立的自包含HTML，可打开hairline-*.html并点击play查看巡游；kernel.js与原始bench保持不变。台钳、坡道、唱片机巡游依次停在左侧(120,150)、中右(240,160)、右下(290,190)，然后离开复位；卡架依次访问三个不同卡片带，然后离开。

侧重规则1固定命中区域、3限制位移、4仅用描边强调、5设计静态构图、7共用并可休眠的时钟、8连续输入弹簧/离散选择缓动、9圆角实体和10图内无文字；卡架另使用规则2距离错峰。

四份look命令最终均返回0。已查看八状态拼图及16帧运动拼图：小图可辨认钳口/螺杆/手柄、卡片页签/托盘、坡面/扶手/两端平台、唱盘/沟槽/唱臂；静态有单个强调点，运动中无明显闪烁或穿帮，低/高强度不出框，明暗主题无遗留错误色，图内无文字，控制台无错误。空状态和来源匹配检查不适用。

台钳运动像素34%、唱片机10%的提示保留：动作集中于活动钳口和唱臂，固定机身不移动，避免教学插图喧宾夺主。卡架边缘测试点在命中范围之外，输出rest符合预期。自动巡游的主观叙事尚未经用户判断。

# 六类体验信号插图

- sorting-tray：分类盒的分隔区和卡片堆对应理解与分类；横移指针带动卡片堆归位，读数sorting。
- balance-scale：天平的横梁、支点、两只吊盘对应权衡选择；横移指针改变倾角，吊盘随动，读数balance。
- spring-box：带合页盖和螺旋弹簧的盒子对应预期与意外；指针展开盖子、升起弹簧，读数spring。
- folding-ruler：带刻度和铰接点的折尺对应重复步骤与负担；指针连续伸展折尺，读数extend。
- hourglass：双端盖、支柱、收腰玻璃和砂堆对应等待与不确定；指针倾转整体，读数tilt。
- retracting-reel：带出带口、刻度带和端钩的卷线器对应退出与恢复；指针伸缩刻度带，读数retract。

静止读数均为rest。所有独立HTML的play巡游依次停在左侧(120,150)、中右(240,160)、右下(290,190)，随后离开复位。每幅HTML可直接打开；加?play=1可自动巡游。页面内保持按需悬停，不自动循环。

使用规则1固定命中、3限幅、4单一描边强调、5设计静态构图、7按需共用时钟、8连续输入使用弹簧、9圆角实体、10图内无文字；kernel与bench未改。六份look最终均退出0，主Agent已查看全部八状态拼图和16帧运动拼图。小图能区分六物件，静态有强调点，动作有界，未见明显闪烁，控制台无错；明暗主题与边界检查通过，图内无文字。空状态和来源匹配检查不适用。

保留提示的理由：折尺覆盖率22%来自水平折叠物件的长宽比，已放大至234px宽；分类盒20%与卷线器17%的运动像素提示保留，因为只移动卡片堆与刻度带，不移动固定外壳，避免悬停时整物漂浮。自动巡游的叙事尚未经用户判断。

## 共同边界：三张卡片插画（2026-10-19）

- index-box：沿用技能 Riffle 的索引盒构造；指针选择卡片，卡片抬起、邻卡按距离错时让开。规则 1、2、4、5、6、8、9、10。巡游依次为 (160,160)、(200,120)、(280,120)、离开。
- device-stand：带屏幕、键盘与触控板的笔记本，以及有听筒与底座的手机；指针横向位置驱动两端轻转。规则 1、3–10。巡游依次为 (120,150)、(240,160)、(290,190)、离开。
- trackball：有掌托、成对按键和滚轮的轨迹球；外壳固定，指针驱动球面线转动。规则 1、3–10。巡游依次为 (120,150)、(240,160)、(290,190)、离开。

三幅独立 HTML 均通过 look.mjs 的边界、读数、页面错误与静止检查；已查看八格检查图和运动接触表。缩略图中能识别索引卡、设备屏幕和轨迹球，静态姿态有焦点；没有文字、穿透的远边或自定义颜色。索引卡的离散选择使用默认 tween，设备与球面使用默认 spring；指针只使用固定坐标范围，离开复位；内核和 bench 未修改。

轨迹球的像素变化为 7%，工具提示动效偏轻；保留这一幅度，因为真实轨迹球转动时外壳和球体轮廓均固定，球面线只作轻量反馈，避免整个设备浮动。其余两幅的变化可明确辨认。巡游尚未得到使用者评价；独立 HTML 可用 ?play=1 自动预览。
